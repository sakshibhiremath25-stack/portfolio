Laser Security System

Developed a microcontroller-based laser security system to detect unauthorized entry using an invisible laser beam perimeter. Designed as a cost-effective and power-efficient alternative to traditional security systems.

Technologies & Components Used:

  • 8051 Microcontroller
  • LDR Sensor
  • LM358 Operational Amplifier
  • Laser Diode
  • Relay & Buzzer
  • Embedded C using Keil µVision

Working Principle:

The laser beam continuously falls on the LDR sensor. When an intruder interrupts the beam, the resistance of the LDR changes. This signal is amplified and sent to the 8051 microcontroller, which activates a buzzer via a relay to alert about the intrusion.

Key Features:

  • Real-time intrusion detection
  • Low power consumption
  • Reliable and scalable design
  • Suitable for homes, banks, museums, and industries
